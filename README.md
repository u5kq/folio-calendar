# folio.calendar

予定・タスク・メモをひとつにまとめる、シンプルなカレンダーアプリです。

## 主な機能
- 月・週・日のカレンダー表示
- 予定の追加・編集・削除
- プライベート・仕事・その他の分類
- タスクの登録・期限・優先度・完了管理
- メモの作成・削除
- 予定・タスク・メモの検索
- 利用状況の確認
- JSON形式でのバックアップと復元
- iPhone向けレイアウトと日本語表示

## データについて
データは利用中のブラウザ内に保存されます。ブラウザのデータ削除や端末変更の前に、設定画面からバックアップを書き出してください。現時点ではクラウド同期には対応していません。
